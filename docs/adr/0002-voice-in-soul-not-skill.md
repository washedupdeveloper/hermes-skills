# The voice lives in `SOUL.md`, not in a skill

**Decision.** The communication contract is the agent's identity, injected every turn.
`caveman` and `reply` remain its on-demand long form.

**Why.** A skill is chosen per task and may not be chosen; a contract that can be skipped
is a suggestion, and "used when relevant" is not a standard a communication rule can meet.

**Cost accepted.** ~500 tokens on every turn, including turns where brevity is irrelevant,
and it cannot be made conditional.

**Consequence.** A reviewer profile is its own `HERMES_HOME`, so the file is versioned per
bot; a global `SOUL.md` does not reach one.
